# Approved build outcomes

## Source-backed project archive
- Use ALL supplied documents and photographs as the primary source material.
- Read and analyze the supplied newsletter and photobook before building the site.
- Create a master list of every CDF project mentioned across the supplied materials.
- Cross-reference the newsletter and photobook so information and photographs are connected to the correct projects.
- Avoid duplicate projects.
- Do not invent facts, statistics, dates, names, locations, achievements, or photograph descriptions; omit unavailable information.
- Preserve important names, figures, dates, and wording from the source materials.
- Flag source discrepancies rather than silently choosing one.

## Website information architecture
- Provide a polished, easy-to-navigate CDF Project Showcase Blog with Home, All CDF Projects, individual project stories where enough information is available, Photo Book / Gallery, Newsletter, About, and Contact sections.
- Home includes a strong CDF hero, short overview, featured projects, documentary photographs, key highlights, latest newsletter/news, and a clear explore-all-projects action.
- The All Projects directory shows every project found in the supplied documents with available name, location, category, description, purpose/impact, dates/completion, statistics, photographs, captions, and source information.
- Organize projects into sensible categories such as Education, Health, Water, Roads/Infrastructure, Youth, Women, Community Development, Security, Electrification, and Other source categories.
- Provide an easy-to-scan project index/filter with search, category filters, location filters when available, thumbnail cards, and links to relevant project details.
- Individual project stories cover need, action, place, beneficiaries, result, and supporting photographs only when supported by the sources.

## Photo book and newsletter experience
- Turn the supplied photobook into a beautiful online photo gallery organized by project or source category.
- Use high-quality image presentation, source-backed captions, correct project associations, and an accessible lightbox/gallery experience.
- Preserve the newsletter title/date, main stories, project updates, announcements, achievements, relevant photographs, and links to related project pages.
- Organize multiple newsletter editions chronologically if more than one is supplied.

## Design and quality
- Make the website professional, trustworthy, community-focused, and modern rather than a generic template.
- Use a clean light background, source-identifiable brand colors, professional typography, large documentary-style photography, subtle animations, clear cards, mobile responsiveness, accessible navigation, and fast loading.
- Confirm every project appears somewhere on the website, photographs are matched as accurately as possible, spelling/names/dates/numbers are checked against sources, duplicate content is removed, desktop/mobile layouts are usable, and navigation is intuitive.

## Delivery
- Deliver a complete working website, not a mockup.
- Serve the complete route manifest at `/manus-routes.json`.
- Build and checkpoint the static site after validation.
